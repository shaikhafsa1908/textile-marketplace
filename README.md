🧵 Textile Marketplace AI

A modern B2B Textile Marketplace that connects buyers with textile suppliers through an intuitive marketplace and an AI-powered Fabric Sourcing Assistant.

The platform allows buyers to explore textile products, search and filter fabrics, save favorites, and receive intelligent fabric recommendations using AI.

⚙️ Installation

Clone the repository

git clone https://github.com/shaikhafsa1908/textile-marketplace.git

Install frontend dependencies

npm install

Install backend dependencies

cd server
npm install

Start the backend

node server.js

Start the frontend

npm run dev
